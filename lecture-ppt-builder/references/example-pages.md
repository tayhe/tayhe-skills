## s_cover 封面 → reference_pages/01_cover_封面_利特拉斯.jpg

```python
pg()
s_cover("人的法则与神的法则",
        "索福克勒斯《安提戈涅》：城邦权力的边界",
        "西南石油大学 · 政治哲学课程　何舒骏",
```

结语页可用同一幅画闭环（首尾呼应）。

## s_dark 深色设问页 → reference_pages/02_dark_深色设问页.jpg

```python
s_dark("导言 · 本讲问题", "城邦的权力有没有边界？",
    [("设问一：", "公开的城邦的法之上，是否还存在一种更高的、隐秘的法？"),
     ("设问二：", "公共的理性、城邦的法律，是否真的具有压倒人类古老的血亲纽带、"
                  "家庭神圣信仰与地下原则的资格？"),
     ("设问三：", "人的政治知性（Logos）是否是一种自负——它与自己所不得而知的隐秘命运、"
                  "与自身存在的原初污秽必然关联，从而将遭遇怎样不可逾越的形而上学深渊？")],
```

要点：手稿的设问句做成深色页统摄后续分页；kicker 带手稿位置（导言 · 本讲问题）。

## s_compare 双栏对照页 → reference_pages/03_compare_双栏对照页.jpg

```python
s_compare("2.3 · a · 词义分析", "ὅσια πανουργήσασα：一个修辞学的矛盾体", pg(),
    lead="「犯了圣洁的罪行」（74 行）——这个悖谬短语由两个互相冲突的词构成：",
    left=dict(head="πανουργήσασα", sub="πᾶν-（一切）+ ἔργον（行为）· 不定过去时分词",
        items=[("原义：", "「什么恶事都干得出来的人」；"),
               ("引申：", "在主权法权视角下——作奸犯科、犯下大逆不道的歹事：行凶作恶。")]),
    right=dict(head="ὅσια", sub="hosios 的复数中性宾格",
        items=[("词义：", "圣洁的事、神的法所许可的事；"),
               ("归属：", "属于幽冥与永恒的法度，而非尘世的法令。")]),
    bottom="这个矛盾体指出了这样一种可能性：在尘世法律看来是大逆不道的罪，"
           "在幽冥与永恒的法度中，却是不可逃避的神圣天职。")
```

要点：双栏只放对立两极，每栏 2–3 条；结论条一句话说透矛盾的综合。希腊语直接做标题。

## s_content 象牙图文页

```python
s, tw = s_content("2.1 · 为何是终极绝罚", "在古希腊人的宗教伦理中，禁葬意味着什么？", pg(),
    lead="在现代人眼中尸体仅具生物学意义；但在古希腊人的世界观中，禁葬是超越死亡本身的终极绝罚。")
bullets(s, M, 2.5, tw, [
    ("a. 政治身份的开除：", "葬礼是政治共同体承认死者为「我们中的一员」的最后仪式——"
        "剥夺安葬、交由鸟兽啃食，意味着将波吕涅刻斯彻底开除出城邦共同体；"),
    ("b. 灵魂归宿的剥夺：", "完成葬礼才是灵魂过渡冥界的标志——不得安葬者无法渡过冥河（Styx），"
        "永世漂泊（参见帕特罗克洛斯托梦、埃尔佩诺尔的哀求）；"),
    ("c. 人的尊严的弃绝：", "尸体被飞禽野犬分食（thērobora，兽食），意味着死者不再拥有完整的"
        "「人」的形态（Gestalt）——从「人类」向「兽类食物（bora）」的存在论降级。"),
], size=15.5, gap=9)
point_bar(s, M, 6.15, tw, "克瑞翁不仅剥夺了波吕涅刻斯的城邦公民身份，"
    "更把惩罚延长到死后永恒——剥夺他在冥府安息的权利。", size=15.5)
```

要点：手稿 a/b/c 枚举的引导语加粗带编号；术语（Styx / thērobora / Gestalt / bora）
随文括注；point_bar 是这一页唯一论点的收束，不要写成总结陈词。

## s_cards 卡片页

```python
s_cards("导言 · 文献学背景", "「忒拜三部曲」：并非一次写成的三联剧", pg(), [
    ("①", "《安提戈涅》", "上演最早（约前 442/441），讲的却是故事时间最晚的情节——"
        "兄弟相残之后，安提戈涅违令葬兄。"),
    ("②", "《俄狄浦斯王》", "约前 429 年上演，讲述俄狄浦斯杀父娶母的悲剧——"
        "解开「人」之谜的人不认识自己。"),
    ("③", "《俄狄浦斯在科罗诺斯》", "写盲眼的俄狄浦斯在安提戈涅陪伴下的流亡与死亡，"
        "直到前 401 年、诗人去世后才上演。"),
], cols=3,
    bottom="三部剧各自独立，其间的呼应是主题性的，而非情节设计——本讲以《安提戈涅》为讲授主体。")
```

要点：单卡正文控制在 ~80 字内；超过就降级为 s_content + bullets（文字量是硬性约束，溢出必现）。

## 措辞节奏（看不见的审美）

- 引导语一律「名词短语：」加粗，正文以完整句承接，破折号「——」带出解释层；
- 每页结论条只收束本页论点，禁止复述上文；
- 引文保持手稿断行（诗行感），不并段；
- 页与页之间用深色页「换气」：约每 6–8 个象牙页插一页 s_dark 或 s_quote。
