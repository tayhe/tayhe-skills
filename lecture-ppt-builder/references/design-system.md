# 「剧场与纸」设计体系规范

旧蓝白企业模板风（色块卡片、图片只作右侧装饰、正文小字密集）已被否决，禁止复用。
现行体系于 2026-09-21（第一讲）确立，次日（第一讲 B）验证可复用，2026-09-27 自包含化。

## 1. 设计基调

课程讲血亲复仇、神义冲突、法治诞生——PPT 应该是**剧场**，不是工作汇报。
整体气质：博物馆图录 / 古籍纸页。引文页与章节页用满版古典油画 + 暗化遮罩制造剧场感；
象牙内容页保持纸面呼吸感，一页一个论点。

## 3. 字体

- 思源宋体（Noto Serif SC）：标题与正文
- 思源黑体（Noto Sans SC）：眉标（kicker）、图注、辅助信息
- 华文楷体：引文（引文页正文、页面内嵌引语）
- Times New Roman：西文、数字、页码

中文必须同时设置 latin+ea+cs 三处 typeface（模板 `_cjk()` 已处理），否则回退成默认字体。

| 深色页正文 | 18 |
| bullets 正文 | 16–17 |
| 对比栏正文 | 16 |
| 卡片正文 | 15（卡片是底线，勿再低） |
| 结论条 | 16.5 |

**铁律：正文不得低于 15pt，引文不得低于 20pt。** 15 以下只允许眉标、页码、图注、引文出处行。

## 5. 画布

13.333 × 7.5 英寸（16:9），外边距 M=0.62 in，页脚 y=7.12。

## 6. 页面模板与论证功能

每种页型承担一种论证功能，按手稿内容选型，不要混用：

| 模板 | 功能 | 典型场景 |
|---|---|---|
| s_cover | 封面 | 满版主题油画 |
| s_section | 章节页 | 满版画 + 96pt 大序号 |
| s_quote | 引文页 | 文本细读；引文必带行号出处（如「——《安提戈涅》450–470」） |
| s_dark | 深色思辨页 | 核心命题；设问句统摄后续 a–d 分页 |
| s_content | 象牙图文页 | lead 斜体导语 + bullets + point_bar 结论条 |
| s_compare | 双栏对照 | 概念对决（Bia vs Peithō、Kērygma vs Nomima） |
| s_cards | 卡片页 | 并列要点；**单卡正文 >80 字时改用 s_content+bullets**，否则溢出 |

每页一个论点，页底 point_bar 收束。页面顺序与手稿标题层级逐节对应：
- 页眉 kicker 一律带手稿编号：`2.1 · 为何是终极绝罚`、`3.4 · a`、`《欧墨尼得斯》· 3.4 小结`
- 手稿的 a–d 枚举必须逐条做成独立分页（不得合并打散），「小结」必须显式保留
- 手稿的设问句可做成深色设问页统摄后续分页
- 引文页 kicker 带篇名+行号：`《安提戈涅》· 三重抗辩 450–470`

## 7. 素材约定

### 通用原则
- 只用**考据过的高清图**（古典油画、大理石立像、陶瓶画、遗址照片，文件名带作者/馆藏出处）。
  低清碎片、无出处的网图禁止使用。
- 按主题分组存放（如 `神话专题_XXX家族`、`城邦制度`、`悲剧与法治`），
  模板顶部的分组常量（PHIL/CIV/CITY/TRAGEDY/ATREUS/THEBES/GODS）指向这些目录，
  迁移到新项目时按实际目录结构调整即可。
- 原项目实例：`assets/hd_images/` 七组 98 张（01_哲学思想与范式、02_希腊地理与文明演进、
  03_城邦制度与公民实践、04_希腊悲剧与法治创制、神话专题_阿特柔斯家族、
  神话专题_忒拜家族、神话专题_诸神_特洛伊与忒拜）。

### 焦点裁切（FOCUS）
- 一切图片走 `cover_pic()` 焦点裁切，禁止拉伸、禁止中心裁切。
- 裁切窗口以焦点 (fx, fy) 为中心；未登记默认 (0.5, 0.38)——古典油画/立像面部多在画面上 1/3 处。
- **新图入库必须在 FOCUS 表登记焦点，并渲染预览验证人物面部**（这是旧版"切头留腿"事故的对策）。
- 模板内置的 46 条焦点是原项目素材档案，新项目用自己的图时自行登记。

### 带框/白边照片
素材照片若带画框或白边（如画册翻拍），先用 `precrop()` 按比例预裁再入库使用。
已知必须预裁的（原项目实例）：
- `16_...Lytras.jpg`（金色画框，precrop 0.07/0.065/0.93/0.94）
- `09_爱琴海全景_圣托里尼...jpg`（白边，precrop 0.02/0.05/0.98/0.95）

### 素材名实不符警告
**文件名不可尽信**：原项目 `03_城邦制度与公民实践/17_雅典古市集阿塔罗斯柱廊_Stoa_of_Attalos_Agora.jpg`
实为一件蛇形雕塑照片（2026-09-22 发现）。新图使用前必须 Read 目检原图确认内容。

## 8. 工具链坑清单（全部踩过，勿再踩）

1. **Edit 工具同消息内多个调用会互相覆盖丢编辑**：改 build 脚本时一次一个 Edit，
   或用 Python 脚本读全文 `replace` 原子写入（每个替换带 `assert count==1` 校验），改完 Grep 验证再构建。
2. **Read 工具有图片缓存**：渲染后复查同一页必须先 `cp 幻灯片N.PNG chk_N.png` 复制成新文件名再读。
3. **Windows Git-Bash 环境**：若在 Windows git-bash 下 `ls` / `cp` 找不到，先 `export PATH="/usr/bin:/bin:/usr/local/bin:$PATH"`。
4. **Python 环境与包管理**：项目统一使用 `uv`（如 `uv run build_xxx.py`，依赖按 PEP 723 声明自动解析），严禁裸 venv 跑脚本。
5. **渲染脚本跨平台支持**：内置双引擎适配（Linux 下调用无头 LibreOffice + pdftoppm，Windows 下调用 PowerPoint COM）。
6. **渲染脚本的 pptx 路径必须给绝对路径**（避免渲染引擎与 COM 自动化解析工作目录歧义）。
7. **标点孤行检查**：长句以「，」「：」「——」结尾换行时会出现标点孤行，渲染后逐页目检并精简措辞。
8. **引文 ≥7 行**：s_quote 已自动缩 20pt + 收紧行距，且代码级校验总字数与段数，渲染后仍要确认底部出处行没被撞。
9. **希腊语/拉丁语与中西文混排**：中西文混排时 `_cjk()` 必须将 `run.font.name` 设置为西文字体（`Times New Roman` 或 `Liberation Serif`），CJK 字体仅赋给 `a:ea` 节点；否则希腊字母与西文字符会被中文字体解析为全角/等宽字符而发生排版溢出与字符挤压。
