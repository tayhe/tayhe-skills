## 1. 设计基调

课程讲血亲复仇、神义冲突、法治诞生——PPT 应该是**剧场**，不是工作汇报。
整体气质：博物馆图录 / 古籍纸页。引文页与章节页用满版古典油画 + 暗化遮罩制造剧场感；
象牙内容页保持纸面呼吸感，一页一个论点。

## 3. 字体

- 思源宋体（Noto Serif SC）：标题与正文
- 思源黑体（Noto Sans SC）：眉标（kicker）、图注、辅助信息
- 华文楷体：引文（引文页正文、页面内嵌引语）
- Times New Roman：西文、数字、页码

中文必须同时设置 latin+ea+cs 三处 typeface（模板 `_cjk()` 已处理），否则回退成默认字体。

## 6. 页面模板与论证功能

每种页型承担一种论证功能，按手稿内容选型，不要混用：

| 模板 | 功能 | 典型场景 |
|---|---|---|
| s_cover | 封面 | 满版主题油画 |
| s_section | 章节页 | 满版画 + 96pt 大序号 |
| s_quote | 引文页 | 文本细读；引文必带行号出处（如「——《安提戈涅》450–470」） |
| s_dark | 深色思辨页 | 核心命题；设问句统摄后续 a–d 分页 |
| s_content | 象牙图文页 | lead 斜体导语 + bullets + point_bar 结论条 |
| s_compare | 双栏对照 | 概念对决（Bia vs Peithō、Kērygma vs Nomima） |
| s_cards | 卡片页 | 并列要点；**单卡正文 >80 字时改用 s_content+bullets**，否则溢出 |

每页一个论点，页底 point_bar 收束。页面顺序与手稿标题层级逐节对应：
- 页眉 kicker 一律带手稿编号：`2.1 · 为何是终极绝罚`、`3.4 · a`、`《欧墨尼得斯》· 3.4 小结`
- 手稿的 a–d 枚举必须逐条做成独立分页（不得合并打散），「小结」必须显式保留
- 手稿的设问句可做成深色设问页统摄后续分页
- 引文页 kicker 带篇名+行号：`《安提戈涅》· 三重抗辩 450–470`

### 焦点裁切（FOCUS）
- 一切图片走 `cover_pic()` 焦点裁切，禁止拉伸、禁止中心裁切。

- **新图入库必须在 FOCUS 表登记焦点，并渲染预览验证人物面部**（这是旧版"切头留腿"事故的对策）。

### 带框/白边照片
素材照片若带画框或白边（如画册翻拍），先用 `precrop()` 按比例预裁再入库使用。

## 8. 工具链坑清单（全部踩过，勿再踩）

1. **Edit 工具同消息内多个调用会互相覆盖丢编辑**：改 build 脚本时一次一个 Edit，
   或用 Python 脚本读全文 `replace` 原子写入（每个替换带 `assert count==1` 校验），改完 Grep 验证再构建。
2. **Read 工具有图片缓存**：渲染后复查同一页必须先 `cp 幻灯片N.PNG chk_N.png` 复制成新文件名再读。
3. **Windows bash 工具先 `export PATH="/usr/bin:/bin:/usr/local/bin:$PATH"`**，否则 ls/cp 等不存在。
4. **Python 用 `C:\Users\tayhe\.workbuddy\binaries\python\envs\default\Scripts\python.exe`**
   （含 python-pptx / python-docx / Pillow / pywin32）；项目 `.venv` 是 WSL 建的，Windows 下不可用。
5. **渲染脚本的 pptx 路径必须给绝对路径**（PowerPoint COM 不解析相对路径）。
6. **标点孤行检查**：长句以「，」「：」「——」结尾换行时会出现标点孤行，渲染后逐页目检并精简措辞。
7. **引文 ≥7 行**：s_quote 已自动缩 20pt + 收紧行距，不用手动处理，但渲染后仍要确认底部出处行没被撞。
8. 希腊语/拉丁语术语行：确认无乱码（如 `οὐ συνεχθεῖν, ἀλλὰ συμφιλεῖν ἔφυν`），字体回退会导致方框。
